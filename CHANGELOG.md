# Changelog

All notable changes to Lenovo Control will be documented in this file.

## [0.1.0] - 2026-09-10

### Added

- Windows system-tray application
- Battery profile detection
- Windows Balanced profile detection
- Performance profile detection
- Active-profile indicator
- Native `PowerGetActiveScheme` integration
- Native `PowerSetActiveScheme` integration
- Graceful handling of unavailable profiles
- Tray exit command

### Not included yet

- CPU temperature monitoring
- Lenovo thermal-mode switching
- Windows startup integration
- Custom application icon
